Snake Game
Trabalho desenvolvido para a disciplina de backend, onde escrevemos um jogo com a linguagem java.
Objetivo do jogo
Guiar o personagem pelo tabuleiro para comer o máximo de maçãs possivel sem bater em nada.

Como jogar
Ao abrir o jogo, pressione qualquer seta para começar.
O personagem anda sozinho, na direção atual. As setas só mudam para onde ele virar.
